About this site

Before you start using this site, you'll want to take a moment to understand how it is organized.

This website presents technological tools you can use to aid your instruction. These Tech Tools are sorted into six domains based on their function (see below). Within each domain, Tech Tools are then sorted into strands based on how they help you accomplish each step in implementing the broader educational strategy. Each domain has its own page with filters and a strand index.
